Quotabit

An iOS app and widget that shows usage from a JSON link you provide. A companion agent can build the feed from your own Grok usage page.

FAQ

What is Quotabit?

Quotabit is an independent iOS app and widget. You paste a JSON feed URL; the app displays percentage, reset date, tokens, credits, plan, and account name when those fields are in your file.

How do I set up the feed?

Publish a JSON file on storage you control (for example GitHub or Google Drive), then enter that HTTPS URL in Settings. A companion agent you set up can keep the file up to date from your own usage page.

Does Quotabit collect my data?

No. There is no account, analytics, ads, tracking, or third-party SDK. The app only fetches the feed URL you enter. Details are in the privacy policy.

The widget is not updating

Confirm the URL is reachable over HTTPS and that the file is valid JSON. Check Background App Refresh, then open the app once so it can refresh. Use Reset in Settings if you need to start over.

How do I get help?

Email aduserx+keep@mail.grokbot.com with what you expected, what you saw, and your iOS version. We read every message.

Quotabit

Une app iOS et un widget qui affichent votre usage à partir d’un lien JSON que vous fournissez. Un agent compagnon peut constituer le fil à partir de votre propre page d’usage.

FAQ

Qu’est-ce que Quotabit ?

Quotabit est une app iOS et un widget indépendants. Vous collez l’URL d’un fichier JSON ; l’app affiche le pourcentage, la date de réinitialisation, les tokens, les crédits, le plan et le nom du compte lorsqu’ils figurent dans votre fichier.

Comment configurer le fil ?

Publiez un fichier JSON sur un stockage que vous contrôlez (par exemple GitHub ou Google Drive), puis saisissez cette URL HTTPS dans Réglages. Un agent compagnon que vous configurez peut tenir le fichier à jour depuis votre page d’usage.

Quotabit collecte-t-il mes données ?

Non. Pas de compte, pas d’analytics, pas de publicité, pas de suivi, aucun SDK tiers. L’app ne fait que télécharger l’URL de fil que vous indiquez. Le détail est dans la politique de confidentialité.

Le widget ne se met pas à jour

Vérifiez que l’URL est accessible en HTTPS et que le fichier JSON est valide. Contrôlez l’actualisation en arrière-plan, puis ouvrez l’app une fois pour forcer un rafraîchissement. Utilisez Réinitialiser dans Réglages si besoin.
